# 今天吃什么

一个给自己用的家常菜菜单。抽菜、配一桌、管理菜库，带图片。
纯静态页面，没有后端，扔进 GitHub Pages 就能用。

## 部署

1. 新建仓库，把这些文件放进去（保持目录结构）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。
4. 手机上打开后「添加到主屏幕」，用起来就跟 App 一样。

本地预览别直接双击 `index.html`（`file://` 下浏览器会拦掉 `fetch`，读不到菜库）。用：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

## 文件

```
index.html            页面结构
style.css             样式（跟随系统深浅色：浅色是纸菜牌，深色是黑板）
app.js                全部逻辑
data/dishes.json      初始菜库，84 道家常菜
images/               自己的菜品图片放这里
manifest.webmanifest  加到主屏用
icon.svg              图标
```

## 数据存在哪

第一次打开时，`data/dishes.json` 会被读进浏览器的 **IndexedDB**，之后所有增删改、图片、吃过的记录都只在 IndexedDB 里，不回写仓库。

意思是：

- 数据是**按设备、按浏览器**分开的。手机和电脑各是一份，不会自动同步。
- 清浏览器数据 = 清菜库。
- 菜库页最下面有「导出备份」，会下载一个 JSON（图片也在里面）。换设备或清缓存前导一份，到新设备上「导入备份」即可。

## 加图片的两种方式

**方式一：直接上传（推荐，最省事）**

菜库 → 点某道菜右边的 `···` → 「上传图片」。图片会被压到长边 900px 的 JPEG 再存进 IndexedDB，一张大概几十 KB。

**方式二：放进仓库**

把图片扔进 `images/`，然后在那道菜的编辑框里填相对路径：

```
images/hongshaorou.jpg
```

这样图片跟着仓库走，换设备也在。也可以填任何外部图片的完整网址。

## 加菜、删菜

- 加：菜库页右上「加菜」，填菜名和标签，保存后可以立刻配图。
- 改：点 `···` 展开，菜名、分类、主料、做法、口味、用时、备注都能改，失焦自动保存。
- 删：`···` → 「删掉这道菜」。
- 不想删但最近不想吃：`···` → 「暂时不抽」，它就不会被抽到，但还在菜库里。

## 想改默认菜库

直接编辑 `data/dishes.json`，一行一道菜：

```json
{"id":"d001","n":"红烧肉","c":"荤菜","m":"猪肉","k":"炖","t":"浓香","min":90,"fav":false,"on":true,"note":"","img":""}
```

| 字段 | 含义 | 取值 |
|---|---|---|
| `id` | 唯一 ID | 任意不重复字符串 |
| `n` | 菜名 | |
| `c` | 分类 | 荤菜 / 素菜 / 汤羹 / 主食 / 凉菜 / 早餐 |
| `m` | 主料 | 猪肉 / 牛肉 / 羊肉 / 鸡肉 / 鱼虾 / 蛋 / 豆制品 / 蔬菜 / 菌菇 / 米面 |
| `k` | 做法 | 炒 / 炖 / 蒸 / 煮 / 焖 / 煎炸 / 凉拌 |
| `t` | 口味 | 清淡 / 咸鲜 / 香辣 / 麻辣 / 酸甜 / 酸辣 / 浓香 |
| `min` | 大概用时（分钟） | 数字 |
| `on` | 是否参与抽签 | true / false |
| `img` | 图片 | `images/xxx.jpg`、完整网址，或留空 |

改完在菜库页点「恢复初始菜库」才会重新读取（注意：这会覆盖你在网页里加的菜）。

想改筛选项本身（比如加一个「粤菜」分类），改 `app.js` 顶部的 `CATS` / `MAINS` / `METHODS` / `TASTES` 四个数组，再同步改 `data/dishes.json`。

## 抽签规则

- 抽菜时会按筛选条件过滤，并跳过最近 N 天按过「就吃它」的菜（N 在筛选里的「重样」设置，默认 7 天）。
- 如果条件太窄导致没菜可抽，会自动放宽「不重样」这一条，并提示一下。
- 「配一桌」按分类凑：两菜 = 荤 + 素，三菜一汤 = 荤 + 素 + 汤，四菜一汤 = 荤 + 荤 + 素 + 汤。其他筛选条件照样生效。
